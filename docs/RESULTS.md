网页演示可使用这些真实录制记录：

```powershell
.\.venv\Scripts\python.exe scripts/import_recordings.py
```

该命令只导入已记录的实际运行，不调用模型、不重新计算成绩。离线审计命令见 [EVALUATION_AUDIT.md](EVALUATION_AUDIT.md)；审计检查报告一致性，不改变原有业务成绩。
